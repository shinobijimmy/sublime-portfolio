# Sublime Design — Master Spec v0.1

**Estado:** Discovery  
**Fecha:** 2026-08-15  
**Dirección visual:** aprobada como punto de partida; se detallará en el lenguaje visual.

## Propósito

Sublime Design es un estudio híbrido de diseño y tecnología. Convierte ideas en identidades, interfaces, productos y sistemas digitales. No se posiciona como agencia gráfica tradicional ni software factory: integra dirección de arte, branding, UX/UI, código y tecnología creativa en una misma práctica.

## Hipótesis de posicionamiento

**Design, product and code for ideas that need to become real.**

Este enunciado es provisorio. El slogan y la voz final se definirán luego de analizar las referencias visuales y priorizar el público inicial.

## Audiencia inicial

1. Marcas, proyectos culturales y negocios ambiciosos que necesitan identidad y experiencia digital coherentes.
2. Fundadores y productos tempranos que requieren UX/UI y construcción digital con criterio visual.
3. Estudios o agencias que necesiten colaboración especializada.

## Oferta MVP

- **Brand Systems:** identidad, logo systems, tipografía, editorial y dirección de arte.
- **Digital Experiences:** sitios, landings, ecommerce y campañas interactivas.
- **Product Design:** UX/UI, apps, dashboards y sistemas de diseño.
- **Creative Technology:** frontend a medida, integraciones, automatización, IA aplicada y visualización de datos.

No se publicarán precios ni paquetes cerrados hasta validar la oferta y los casos de uso.

## Diferenciación

Sublime une cultura visual, pensamiento de producto y capacidad técnica de implementación. Su pipeline conceptual es:

`Brand → Identity → Interface → Product → Technology → Intelligence`

## Principios

- Experimental no significa confuso.
- La tecnología debe servir a una idea o necesidad concreta.
- Los proyectos conceptuales se etiquetan con total transparencia.
- El proceso y las decisiones importan tanto como el resultado final.
- Accesibilidad, velocidad y claridad son requisitos de calidad.
- La experiencia será bilingüe completa: español e inglés con igual jerarquía editorial.

## Decisiones aprobadas — 2026-08-15

- Paleta de partida: negro cálido, coral/rosa salmón como acento y blanco/gris claro para contraste.
- Arquitectura idiomática: sitio bilingüe completo ES/EN.
- La aplicación final de color y la tipografía display se definirán dentro del sistema visual, sin replicar literalmente la referencia de Stitch.

## Arquitectura MVP

- Home
- Work (Real / Concept / Experiment)
- Project detail
- Capabilities
- Method
- About
- Lab (solo con experimentos sólidos)
- Contact / Start a Project

Quedan fuera del MVP: Notes, Ask Sublime, Playground, Archive y Community.

## Modelo de proyecto

Cada proyecto contendrá: título, slug, año, estado, tipo, disciplinas, tecnologías, destacado, resumen, material visual y bloques de caso.

Tipos permitidos:

- **Real:** trabajo realizado para un cliente o iniciativa existente.
- **Concept:** exploración ficticia indicada explícitamente como tal.
- **Experiment:** prueba acotada de diseño, código, IA o interacción.

## Estado del contenido para lanzamiento

La arquitectura de Work se construirá desde el inicio, pero las fichas públicas quedarán vacías hasta contar con material y autorización de publicación. No se usarán clientes, métricas, imágenes ni resultados ficticios como relleno.

Reservas de contenido previstas:

- Dos proyectos web realizados con Hostinger AI, con la participación, proceso y herramientas explicados con transparencia.
- Uno o más casos de identidad vinculados a Oliver Sur, según material y permiso de publicación.
- Otras identidades de marca que se incorporarán después de inventariar activos y contexto.

## Concept projects iniciales

Se consideran seis líneas, sin definir aún su estética ni narrativa:

1. Brand — marca cultural.
2. Product — aplicación.
3. AI — herramienta inteligente.
4. Data — visualización o dashboard.
5. Commerce — marca y ecommerce.
6. Experiment — experiencia generativa o WebGL.

## Tecnología

Para el MVP se evaluará Next.js, React y TypeScript con contenido estructurado local o CMS liviano. Formularios, analítica y hosting se decidirán cuando estén validados el contenido y el flujo de contacto.

Firebase, autenticación, base de datos, IA semántica y WebGL no forman parte automática del primer lanzamiento.

## Definition of Done del MVP

- Comunica qué es Sublime y qué hace de inmediato.
- Expone trabajos reales, concepts y experiments con transparencia.
- Hace entendibles capacidades, método y forma de contacto.
- Funciona en móvil y escritorio con buena accesibilidad, rendimiento y SEO.
- Incluye un CTA claro y seguro para iniciar un proyecto.

## Próximas decisiones que requieren aprobación

1. Público comercial prioritario: **marca + experiencia digital** o **producto digital + desarrollo**.
2. Inventario, material y permiso de publicación de los primeros casos reales.
3. Tipografía display final, tras comparar opciones y licencias.
