# Stage 1 — Next.js foundation

This stage turns the approved static preview into a Next.js + TypeScript application.

## Included

- App Router foundation.
- Spanish-first Home with a complete English content toggle.
- Local, version-controlled content.
- Responsive visual system matching the approved preview.
- Semantic structure ready for SEO and backend work.

## Deferred Firebase work

Stage 2 will initialize Firebase environments and App Hosting. Stage 3 will add a protected contact endpoint and Firestore `leads` collection. Authentication, Storage and AI remain out of scope until those functions are needed.
